# Anurag Raghuwanshi - UI/UX & Frontend Portfolio

A high-performance, dark-themed portfolio crafted with an **Obsidian Black & Electric Orange** color combination inspired by modern automotive and connected UI/UX telemetry design systems.

---

## 🎨 Color Palette & Aesthetic

- **Matte Pitch / Deep Obsidian**: `#060608` / `#09090C`
- **Surface / Slate Cards**: `#111116` / `#181820`
- **Electric Orange Accent**: `#FF5500` (Glow: `rgba(255, 85, 0, 0.45)`)
- **Bright Sunset Orange**: `#FF7A1A`
- **Pure Crisp White**: `#FFFFFF`
- **Muted Silver/Slate**: `#8E929E` / `#D1D5DB`

## 🚀 Key Features

1. **Interactive Hero Section**:
   - Status badge indicating open availability for freelance and full-time roles.
   - Dual-tone bold display typography ("UI/UX Case Study Template & Portfolio").
   - Profile visual showcase featuring Anurag's photo with ambient orange neon halo and floating telemetry badges.

2. **VIDA V1 Pro Smart EV Companion Spotlight**:

3. **About Me & Philosophy**:
   - Story bridging design systems, frontend code, and micro-interactions.

4. **Skills & Toolkit**:
   - Categorized cards for **UI/UX & Product Design**, **Frontend Development**, and **Tools & Collaboration**.

5. **Curated Projects & Case Studies**:
   - Filter tabs: *All Projects*, *UI/UX Design*, *Frontend & Web*, *Mobile Apps*.
   - Interactive detail modal popups for deep dives into project specifications, tech stacks, and metrics.

6. **Career Experience & Timeline**:
   - Milestones timeline with glowing orange node markers.

7. **Interactive Contact Section**:
   - Direct cards for LinkedIn and GitHub.
   - Interactive contact form with real-time field validation and toast notifications.

## 🌐 Quick Preview & Deployment

### Run Locally:
You can simply double-click `index.html` to open it in any web browser!

Or run a local development server using Node.js:
```bash
npx serve .
```

### Deploy to GitHub Pages:
1. Create a new repository on GitHub (e.g. `anurag-portfolio` or `<your-username>.github.io`).
2. Push this folder to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Anurag Raghuwanshi Portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
3. In repository Settings > **Pages**, choose the `main` branch and root `/` folder. Your portfolio will be live in seconds!
